# CBOR

Contains scripts to build "Apple-Universal" static libraries of libcbor. Also packages everything up into an XCFramework for easy consumption with Swift packages or Xcode.
Release names refer to the libcbor version used during compilation. You can append an internal suffix after "-" (e.g., 0.13.0-2); the suffix is included in output folder names but ignored when downloading libcbor sources.
